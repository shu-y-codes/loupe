# 05 — UI

**Goal.** Shared chrome, persona selector, Summary / Specifics, upload preview,
named-box help. Widgets stay thin — call the API or shared services.

**Status.** pending

Source of truth is already `specs/loupe-ui-design.md` (solution brief §12 is pointer +
invariants). No note promotion required for chrome.

## Done when

1. Sidebar: persona, trade dates, upload. Same page for every persona.
2. Summary then Specifics; selecting a Summary row drives Specifics. Specifics is
   Why / Impact / Address first; charts only when that persona will look at them.
3. Upload: file → preview / capability disclosure → confirm → sync progress →
   dashboard updates. Unavailable capabilities explained in place (e.g. disabled VWAP).
4. Help on named boxes (KPI tiles and headers), one sentence; skip Why / Impact /
   Address rows and the findings What column.
5. Address is suggestion **text**. No apply or override buttons.

## Files to create

- `ui/` — Streamlit pages, thin API clients
- Optional internal checklists (not extra specs): ship **chrome + Risk** first, then
  Trader, then Analyst, matching the motivations table in the UI spec.

## Tests

Persona switch changes Summary columns; upload preview before commit; VWAP disabled
with reason on daily-only; no apply/override controls in the tree.
